# Allocra

A single-file static landing page for Allocra, a wallet-based planner for allocations across eligible tokenized assets.

## Deploy on Vercel

Import this folder or its Git repository into Vercel. Select **Other** as the framework preset, use the repository root as the project root, and leave the build command and output directory empty. Vercel will serve `index.html` directly.

For a local preview:

```sh
python3 -m http.server 4194
```

Then open `http://localhost:4194`.
