# Allocra

A wallet-based planner for allocations across eligible tokenized assets.

## Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## Setup & Local Run

To preview the application locally:

```sh
python3 -m http.server 4194
```

Then open `http://localhost:4194` in your browser.

## Deployment

Import this folder or repository into Vercel or any static host. Select **Other** as the framework preset and serve `index.html`.
